# ComicViewer

一个基于 WPF（.NET 9）的本地漫画 / 图片查看器。面向「本地漫画库」场景设计：左侧目录导航、右侧连续阅读，便携式单文件发布，无安装、无依赖。

## 功能特性

- **两种查看模式**
  - **漫画模式**：整本漫画垂直连续滚动，真正生效的像素级 UI 虚拟化，边看边加载，滚轮惯性滑动，支持自定义页间距、背景色与自动滚动（`A` 键开关，`+`/`-` 调速）。
  - **图片模式**：支持单张 / 双页并排（`D` 键）与日漫从右到左顺序（`M` 键）；支持适应窗口 / 适应宽度 / 1:1 原图（`1`/`2`/`3`）、左右 90° 旋转（`Q`/`R`/`0`）；`Ctrl`+滚轮以光标为中心缩放，缩放后左键拖动平移（带边界限制）。
- **左侧目录导航**
  - 后台异步扫描子目录与图片张数，大目录不卡顿。
  - 单击目录高亮选中并尝试阅读该目录；双击进入下一级；「返回上一级」保持刚离开的子目录高亮。
- **末页自动续读**：看到最后一页再点击，自动进入下一个同级文件夹，并同步更新左侧目录的当前阅读高亮。
- **快速跳转页码 & 右键菜单**：按 `G` 或点击页码/状态栏即可滑块或输入页码直达；右键（图片模式 `Shift`+右键）提供资源管理器定位、复制图片/路径、旋转、双页、自动滚动等快捷操作；按 `F1` 查看完整快捷键说明。
- **安全删除**：图片模式顶栏「删除」或 `Delete` 键将图片移入回收站（可在设置中开启删除前确认）；若回收站写入失败，会明确询问用户后再决定是否永久删除。
- **打开单图默认保留前文**：通过文件关联或拖放单张图片打开时，默认保留完整目录列表并直接定位到目标图，支持往回翻页（如需旧版截断机制，可在设置中勾选）。
- **智能图片解码**：自动处理路径中的 `#`/`%` 特殊字符、自动校正 EXIF 方向、完整合成 GIF 增量帧，并按系统 DPI 与并发上限平滑解码。
- **便携式配置**：优先读写 exe 同目录 `config.json`，若位于只读目录自动回退到 `%LocalAppData%\ComicViewer\config.json`。

## 交互与快捷键

| 按键 / 操作 | 功能 |
| --- | --- |
| `F11` / `Esc` | 切换全屏 / 退出全屏或关闭浮层 |
| `←` / `PageUp` / `Shift+空格` / `W` | 上一页（首页→上一本） |
| `→` / `PageDown` / `空格` / `S` / `Enter` | 下一页（末页→下一本） |
| `Home` / `End` | 跳至首张 / 末张 |
| `G` / 点击页码或状态栏 | 打开快速跳转页码浮层 |
| `A` / `+` / `-` | 漫画模式：开关自动滚动 / 调整滚动速度 |
| `Ctrl` + 滚轮 | 漫画模式调整显示宽度（防抖记忆）；图片模式以光标为中心缩放 |
| `1` / `2` / `3` | 图片模式：适应窗口 / 适应宽度 / 1:1 原始大小 |
| `Q` / `R` / `0` | 图片模式：左旋 90° / 右旋 90° / 重置旋转与缩放 |
| `D` / `M` | 图片模式：双页并排开关 / 日漫从右到左顺序开关 |
| `Delete` | 图片模式：移入回收站并自动下一张 |
| 右键 / `Shift`+右键 | 漫画模式右键、图片模式 `Shift`+右键打开功能菜单 |
| `F1` | 显示 / 隐藏快捷键说明 |

## 构建与运行

# 调试运行
dotnet run
